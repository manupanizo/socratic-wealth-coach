# Belief register — [User name / session ID]

Coach-maintained. Available to the user, but most users will never open it directly.

This file logs world-view assumptions the user holds that materially shape their strategy — beliefs about economic systems, institutions, governments, currencies, or any other condition they're taking as a given. These are not facts (verifiable) or principles (how to behave) — they are assumptions about how the world works that underpin the strategy.

**Log a belief when:** the user says something that implies a strong assumption about the world — "I don't trust that Social Security will still exist when I retire," "I think the dollar is going to lose a lot of its value," "I assume my government won't go bankrupt in my lifetime." When one surfaces, name it, ask whether they want to formalize it, and log it here.

**Return to this file when:** a decision the user is making seems to depend on a logged belief (surface the connection), or when a returning user comes back to review their strategy (prompt them to revalidate whether beliefs still hold).
